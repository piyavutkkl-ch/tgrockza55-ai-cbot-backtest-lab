# 🌊 หมวดที่ 13: ฟิสิกส์ความขรุขระของราคา (Rough Volatility) และการกระโดดของราคา (Jumps)
### Rough Volatility, Fractional Dynamics & Price Jumps

**ภาพรวมเนื้อหา:** ทฤษฎีความขรุขระของตลาดการเงิน (Hurst Parameter H < 0.5) ที่อธิบายว่าทำไมความผันผวนในกราฟสั้นจึงคมและกระชากกว่า Brownian Motion ปกติ

**ความสำคัญต่อการพัฒนา Bot Trade:** ใช้คำนวณระยะ Stop Loss และ Take Profit เชิงฟิสิกส์ที่แท้จริง ไม่ให้ถูกสวิงสะบัดกิน SL ในช่วงที่ตลาดขรุขระผิดปกติ
