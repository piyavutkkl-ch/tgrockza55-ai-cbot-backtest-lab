# 🌊 หมวดที่ 5: แบบจำลอง Hawkes Processes และการจับกลุ่มคำสั่งผิดปกติ (Event Clustering)
### Hawkes Processes & High-Frequency Trade Clustering

**ภาพรวมเนื้อหา:** แบบจำลอง Self-Exciting Point Process ที่อธิบายว่าการเกิดออเดอร์หนึ่งจะกระตุ้นให้ออเดอร์อื่นตามมาเป็นลูกโซ่ ช่วยในการวัดความตื่นตัวของตลาดและตรวจจับ Flash Crash / News Spikes

**ความสำคัญต่อการพัฒนา Bot Trade:** ตรวจจับว่าตลาดกำลังอยู่ในภาวะเงียบสงบหรือกำลังเกิดพายุคำสั่ง (Trade Clustering) เพื่อสั่งให้บอทเปิดโหมด Scalping ทำรอบเร็ว หรือปิดระบบเพื่อหลบช่วงข่าวกระชาก
